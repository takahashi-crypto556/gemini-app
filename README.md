＃Google Gimini API 名刺自動抽出アプリ
参考教材を基にGoogle Gemini API（LiteLLM）を活用し、名刺画像から必要な情報を抽出して構造化するPython　アプリケーションです。参考教材通りの設計にとどまらず、実務で使うことを想定した業務効率化（DX）を考慮してExcelファイルにきれいにまとめてくれるシステムです。
ーーーーーーーーーー
＃オリジナリティ
＃１.実務に即した抽出項目の追加とAPIキーを安全に扱うこと
＊参考教材の基本実装（会社名,名前）に加えて、実際のビジネス現場で必要な＊＊役職・メールアドレス・電話番号・住所・フリガナ＊＊といった詳細項目を実装しました。
＃２.抽出テスト時に「Comepany_name」の中に「name」が含まれていることでエラーが発生しました。そこで、行頭だけを対象とするように変更しました。加えて、名刺による書き方の違いに対応するために複数候補を設定しました。（Phone/電話番号　等）
＃３.画像の読み込みからAIへの引き渡し、結果の整理までを途切れずにスムーズになるように設定しました。
＃４．'openpyxl'を使ってExcelファイルとして自動出力する仕組みを作りました。また、01~04まで問題なく実行されるようにパイプラインとして完成させました。
ーーーーーーーーーーー
＃工夫した部分
１．APIの使用
  →コード内に直接APIキーを記入するのを避け、Colabのシークレット機能を使用して呼び出すようにしました。
２．モジュール分け
  →エラー原因がすぐに判別できるように01~04の役割ごとに分けたファイルを使用しながら作成しました。
３．Excel出力
  →実務で使用できるようにExcelファイルで視覚的にわかりやすくまとめて保存できるようにしました。

＊01_...ipynb：環境設定・APIキー設定とGemini API の動作確認
＊02_...ipynb：名刺データ構造のモジュール化（'BusinessCard'クラス）
＊03_...ipynb：基本データ構造の実装と名刺テキストの読み込み
＊04_...ipynb：Ecel出力機能の実装と全体パイプラインの動作確認
